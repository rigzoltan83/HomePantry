# HomePantry

HomePantry is a self-hosted household food inventory and recipe management application.

## Planned features

- Household food inventory
- Barcode-based product identification
- Expiration date tracking
- Custom storage locations
- Safety stock levels
- Low-stock alerts
- Expiring and expired item lists
- Ingredient substitutions
- Recipe discovery based on available ingredients
- Prepared food storage
- Hungarian and English user interfaces

## Technology

- Python
- Flask
- PostgreSQL
- SQLAlchemy
- Alembic
- Gunicorn
